# Search 'Em All

## WHERE YOU CAN SEARCH FOR ANY POKEMON IN THE POKEDEX !

- Type in any pokemon name inside of the "Search 'Em All"
- Click the SEARCH button
- You CAN SEE:
    - A Normal Form Of The Pokemon + A Shiny Form Of The Pokemon
    - The Pokemon's TYPE
    - And A List Of All The Pokemon's Moves (100+ Available MOVES)
